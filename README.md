## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅲ 实操篇 · 第9章 AIGC与新闻写作**（教材 Tier 1 实验工具，对应教材实验 9.2，另见实验 2.1 亲测幻觉）。教材命名："多模型对比器"。

**学习目标**：用同一提示词并发询问多个大语言模型，学会并排比较不同 LLM 在新闻写作质量与事实口径上的差异，亲身体验 AI 幻觉的产生方式。

**核心术语**：大语言模型（LLM）、提示词（Prompt）、幻觉（Hallucination）、API 密钥（API Key）

**适合对象**：新闻传播专业学生、媒体从业者、事实核查爱好者

**课前准备**：本工具采用"自带密钥（BYOK）"模式直连模型服务，需准备至少两家大模型服务商的 OpenAI 兼容接口信息（如 DeepSeek、Kimi、OpenAI 的 Endpoint 与 API Key，在页面三栏中分别填写），也可改用教师提供的演示账号；自备密钥请注意用量与保密，课后及时删除。页面本身离线可用，但调用模型接口时需联网。从 GitHub Pages 直连 OpenAI / Anthropic / Gemini 等官方域名时常被浏览器 CORS 拦截，这是静态站架构限制，不是操作错误；无密钥或现场被拦时，用「查看示例对比结果」完成对照。真实请求有 60 秒超时，超时后面板会提示，按钮会恢复可点。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师点内置示例「数据与感受矛盾」，再点「查看示例对比结果（无需 API Key）」，带学生逐栏找出三份回答中互相矛盾或无中生有的细节，引出"口径差异"与"幻觉"两个概念。有演示账号时再点「并发对比 3 模型」做一次真请求。
2. **上手实操**（20 分钟）：学生按教材实验 9.2 步骤完成：①在三栏分别填入接口与密钥（或使用演示账号）；②选定同一新闻写作任务（如把一段采访素材改写成倒金字塔消息，可基于内置"城市拆迁政策"示例改编）；③点击"并发对比 3 模型"；④从事实准确性、导语质量、结构完整度、幻觉出现次数四个维度给三栏回答打分；⑤汇总为一张多模型对比记录表
3. **小组讨论**（8 分钟）：当多个模型对同一事实给出互相矛盾的说法时，记者应如何核实与取舍？本组遇到的最典型幻觉与教材实验 2.1 的案例有何异同？
4. **总结**（4 分钟）：模型输出只是"一种口径"，多模型交叉对比是发现幻觉与偏差的第一道工序，事实最终仍须回到信源核实

**课后作业**：自选本周一条热点新闻，设计同一提示词分别询问两个以上大模型，撰写 500 字对比笔记，指出至少一处事实出入或幻觉，并给出你的核实结论

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
